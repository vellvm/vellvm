This folder contains the meta-theory of VIR: reasoning principles about the
denotation of programs, and refinement results relating the instantiations of the
semantics to one another.

- `Equational.v`  the equational theory of the representation function, transported
  by interpretation.
- `I2F/`          soundness of the lowering from the infinite to the finite memory
  model, established from the denotation up to the top level. See `I2F/README.md`.
